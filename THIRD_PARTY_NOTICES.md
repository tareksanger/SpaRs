# Third-party attribution

This is an independent, experimental port, not an Explosion product. spaCy and Thinc names identify compatibility targets, not affiliation. This project is named SpaRs (`spars` in Cargo).

SpaRs's own code uses the [MIT license](LICENSE). The Cargo crate contains the project license and the spaCy and Thinc notices for translated code. Model weights and linguistic resources are distributed separately and retain the model and Unicode notices listed below. SpaRs does not embed or run Python or Thinc.

| Notice | What it covers |
|---|---|
| [spaCy MIT](licenses/spacy-MIT.txt) | Translated algorithms and copied language rules |
| [Thinc MIT](licenses/thinc-MIT.txt) | Translated neural and hashing operations |
| [Model MIT](https://github.com/tareksanger/SpaRs/blob/main/licenses/en_core_web_md-MIT.txt) | Official model weights and resources |
| [Model source notices](https://github.com/tareksanger/SpaRs/blob/main/licenses/en_core_web_md-SOURCES.txt) | WordNet lemma resources, vector terms, and upstream training-source attribution |
| [Unicode](https://github.com/tareksanger/SpaRs/blob/main/licenses/Unicode.txt) | Character classifications and lowercase mappings |

Native algorithms are translated from official spaCy 3.8.14 and Thinc 8.3.13 source distributed in their official Python wheels. Their separate copyright notices and MIT texts must accompany the translated code. [Source provenance](https://github.com/tareksanger/SpaRs/blob/main/reference/README.md) records hashes verified against wheel RECORD and reviewed differences between official wheels. Source repositories: https://github.com/explosion/spaCy and https://github.com/explosion/thinc.

Relevant translations: matcher/{matcher.pyx,dependencymatcher.pyx}; morphology.pyx; tokenizer.pyx; strings.pyx; lang/lex_attrs.py; lang/en/lex_attrs.py and lemmatizer.py and syntax_iterators.py; ml/models/tok2vec.py and parser.py; ml/_precomputable_affine.py and parser_model.pyx; pipeline/_parser_internals/{_state.pxd,arc_eager.pyx,ner.pyx,nonproj.pyx}; pipeline/{attributeruler.py,lemmatizer.py}; Thinc layers/{hashembed,maxout, layernorm,expand_window,with_array,residual}.py and backends/numpy_ops.pyx.

MurmurHash was written by Austin Appleby and placed in the public domain. The Thinc uint64 specialization is translated from its MIT source; despite its x86_128 function name, the actual operations mix two 64-bit words.

The official en_core_web_md 3.8.0 model metadata declares MIT. Its own LICENSE and LICENSES_SOURCES are preserved under licenses/ in the repository and copied into every model export. The source notices include WordNet 3.0 (Princeton license) and Explosion vectors (CC0), plus training-source attributions. Training-source licenses must not be confused with the model package license. The exporter copies resources from the official model, including lemma lookups; it does not redistribute training data. Official release: https://github.com/explosion/spacy-models/releases/tag/en_core_web_md-3.8.0.

Unicode 15.0.0 classification ranges and lowercase mappings are generated by `tools/lexical.py` using Python 3.12.5's character APIs; the Unicode version is recorded in each model. These resources retain the Unicode notice. Python is a development tool and is not bundled with SpaRs, so its license is not included.

Rust and Node dependencies are separate upstream projects. Their manifests and lockfiles identify versions and declared licenses; a lockfile does not replace license texts. Distributors of compiled libraries or executables must include the applicable notices for dependencies actually linked or bundled into that artifact. Model distributions must retain the model and resource notices. See the [release checklist](https://github.com/tareksanger/SpaRs/blob/main/docs/RELEASING.md).

Native matrix operations use matrixmultiply 0.3.10, available under MIT or Apache-2.0, with its default single-threaded Rust kernels. Cargo.lock pins its dependency versions; no external BLAS installation is required.

The optional native installer embeds a reproducible recipe, linguistic resources, and upstream notices under `installer/resources/`. Its source mapping is generated by `tools/installer_recipe.py` and records which official data supplies each manifest field. Tensor bytes and bulk lookup tables are read from the checksum-pinned official package during installation. Archive, HTTPS, and MessagePack dependencies are isolated in `installer/Cargo.toml` and pinned by its own lockfile.
